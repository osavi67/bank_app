# Bank App

Учебное приложение для учёта личных финансов, которое постепенно развивается в backend-проект на FastAPI.

## Сейчас реализовано

- работа с кошельками;
- простые операции дохода и расхода;
- управление зависимостями через Poetry.

## Требования

- Python 3.15;
- Poetry.

## Запуск

Установить зависимости:

    poetry install

Запустить приложение:

    poetry run python main.py

## Структура проекта

- `main.py` — запуск консольной программы.
- `bank/wallets.py` — получение списка кошельков.
- `bank/operations.py` — расчёты доходов и расходов.

Проект развивается в рамках курса по FastAPI.
